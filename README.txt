STASIUM XII - PC test build (Windows 10/11, 64-bit)
Build: 5 Oct 2026 (c), pc/world-zones fabeb25 - with the first dungeon, the Old Granary Cellar.

1. Download ALL THREE zips and unzip them into the SAME folder:
   StasiumXII_PC_2026-10-05c_part1_game.zip
   StasiumXII_PC_2026-10-05c_part2_data.zip
   StasiumXII_PC_2026-10-05c_part3_data.zip
2. Double-click JOIN_AND_PLAY.bat. The first time it joins the data into StasiumXII.pck, then starts the game.
   After that you can just run StasiumXII.exe.
   SmartScreen: More info -> Run anyway.

Dungeon: walk west from Crossroads to Stoneford, find the granary with the cellar hatch and the Door Keeper,
click the hatch, pick a star and Enter.
Controls: click to walk, Shift+click or double-click to run, R toggles run, Esc for Visuals.
