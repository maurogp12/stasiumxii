STASIUM XII - PC (Windows 10/11, 64-bit)

NEW: the launcher. Download it once, then it keeps the game up to date.
1. Download StasiumXII_Launcher.zip (about 37 MB):
   https://github.com/maurogp12/stasiumxii/raw/pc-builds/StasiumXII_Launcher.zip
2. Unzip it into a folder you can write to (Desktop, Documents...).
3. Double-click StasiumXII.exe. SmartScreen: More info -> Run anyway
   (the game is not code-signed yet).
4. The first start downloads the game (about 600 MB) and checks it.
   After that, each start downloads only what changed, then press PLAY.
   Repair re-checks every file.

STASIUM XII - PC test build (Windows 10/11, 64-bit)
Build: 11 Oct 2026, pc/world-zones eb5bfb9.
New: all five town dungeons - Old Granary Cellar, Frostspire Archive, Saltmaw Grotto, Drowned Abbey, Heart of the Blight.

1. Download ALL 8 zips and unzip them into the SAME folder (a new folder, or over the old build):
   StasiumXII_PC_2026-10-11_part1_game.zip
   StasiumXII_PC_2026-10-11_part2_data.zip
   StasiumXII_PC_2026-10-11_part3_data.zip
   StasiumXII_PC_2026-10-11_part4_data.zip
   StasiumXII_PC_2026-10-11_part5_data.zip
   StasiumXII_PC_2026-10-11_part6_data.zip
   StasiumXII_PC_2026-10-11_part7_data.zip
   StasiumXII_PC_2026-10-11_part8_data.zip
2. Double-click JOIN_AND_PLAY.bat. It joins the game data into StasiumXII.pck, then starts the game.
   After that you can just run StasiumXII.exe.
   SmartScreen: More info -> Run anyway.

Dungeons (click the door or the Door Keeper, pick a star, Enter):
- Old Granary Cellar: Stoneford (west), levels 1-10.
- Frostspire Archive: Northgate (north, snow), levels 10-20.
- Saltmaw Grotto: Eastmarch (east coast, sea cave on the beach), levels 20-30.
- Drowned Abbey: Southbridge (south, chapel by the swamp), levels 30-40.
- Heart of the Blight: Westwatch (far west, the blighted stump), levels 40-50.
Controls: click to walk, Shift+click or double-click to run, R toggles run, Esc for Visuals (Performance mode).
