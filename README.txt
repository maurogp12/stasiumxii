STASIUM XII - PC test build (Windows 10/11, 64-bit)
Build: 10 Oct 2026, pc/world-zones 061df1f.
New: the locked character looks (dark-steel Ironjaw), easier monster selection in dungeons,
Performance mode for slower PCs (Esc > Visual Settings), the new Northgate Crags.

1. Download ALL THREE zips and unzip them into the SAME folder (a new folder, or over the old build):
   StasiumXII_PC_2026-10-10_part1_game.zip
   StasiumXII_PC_2026-10-10_part2_data.zip
   StasiumXII_PC_2026-10-10_part3_data.zip
2. Double-click JOIN_AND_PLAY.bat. It joins the game data into StasiumXII.pck, then starts the game.
   After that you can just run StasiumXII.exe.
   SmartScreen: More info -> Run anyway.

Your hero: the world uses the class you picked (Ironjaw if none).
Dungeon: walk west from Crossroads to Stoneford, find the granary hatch and the Door Keeper,
click the hatch, pick a star and Enter. Hover a monster to see hit % and damage; gold ring = in range.
Controls: click to walk, Shift+click or double-click to run, R toggles run, Esc for Visuals.
