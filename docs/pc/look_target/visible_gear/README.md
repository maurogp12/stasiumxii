# Visible gear (paper doll), PC — approved looks

Mauro, 11 Oct 2026: "quiero que los monos empiecen sin armadura y conforme se pongan piezas se vea el set que estan utilizando, tipo wakfu".

- **Base "no armour" look — APPROVED** ("Sí, aprobada"): plain oatmeal linen tunic, brown wool trousers, soft leather shoes, leather wrist wraps. The same clothes for every class; the class reads from its weapon. This is what a brand-new character wears (also on the character select pedestal and island).
- **Full-coverage rule** (Mauro: "todo su cuerpo deberia verse y tomar forma con el set que tiene puesto"): a worn piece fully replaces the base clothing in its zone — chest = torso + full sleeves + hem; legs = whole trousers; boots = shoes and shins; head may hide the hair; weapon replaces the base weapon. The base shows only in empty slots.
- **Sets:** the PC uses the mobile gear sets (weapon, head, chest, legs, boots; Normal / Rare / Legendary / Ultra).
- **Ironjaw:** Cragmaw (Normal) and Tyrantjaw (Legendary) approved; Pitmaw (Ultra) helm being reworked.
