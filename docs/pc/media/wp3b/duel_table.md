# WP3b Koliseo duel table

Media: none. This package does not change the world picture. The table is the check.

Points are on in Koliseo. The opponent is the same class with no points. The race is exponential: Mastery raises damage done, Vitality raises max HP, Resist lowers damage taken up to its cap. Swift adds Initiative and does not change the race. Healing uses the same Mastery rate and does not change this duel.

The proposed rates (Mastery +0.5% damage and healing, Vitality +0.5% of base max HP, Resist +0.4% less damage taken capped at 25%, Swift +1 Initiative) put an all-Mastery spend at about 59.8% and a mixed spend at about 61.2%. Both leave 45–55%. The rates below keep the same shape and the 25% Resist cap, scaled so the worst spread of the curve's point budget stays inside the band. Class HP per level and title names stay Open.
