# Thunderwell Core floor (L4), STASIUM XII PC

Ship-ready PNGs for the Thunderwell Core combat floor (Godot 4.7.2, linear filter, no mipmaps, straight alpha).
Masters are `<name>@2x.png` and are drawn at half size. Plain `<name>.png` is a half-size Lanczos fallback with the same mode and alpha rules.
Every size is divisible by 4. All raws come from Scenario project `stasium`, model Seedream 4.5 High (4K). Scenario did not expose job IDs for these runs.

## Art notes
- **Lit raw trace colour is lime (hue ~94), not 140** as its Scenario QA note says. This does not matter for `glow_mask` (intensity only, tinted in the shader). Unlit traces in `floor_tiles` were rotated to 140.
- **Unlit raw is very dark** (stone at about 5% luminance), so `floor_tiles` carries a x2.2 lift. If code wants the raw darkness, divide by 2.2 or regenerate the unlit sheet with only the glow removed and the base lighting kept.
- **Tile a is skewed** in both sheets (not a 2:1 diamond, with rim lines along the NW/SW edges). The homography fixes it, but the left half of its stone texture is stretched by about 20%. Regenerate tile a if that stretch shows.
- **Traces do not connect across cell edges.** Each variant's traces end in different places, so the iso floor reads as a random circuit rather than continuous lines. That is fine for random fill. Regenerate the sheet with edge-midpoint trace ports if continuous runs are wanted.
- The pads are a glossy, clip-art "QFP chip" style that is crisper than the painted floor. Hues are on spec after a small nudge. Regenerate in a more painted style only if they clash in-game.
- `room_edge_raw.png` is unusable as a pure gradient (see above). It was replaced by a synthesised vignette.
