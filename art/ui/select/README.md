# Hot-seat class-select plates

Static plates for the Koliseo class cards. Hot-seat and Online share them. Not combat walk strips, and not the old `art/characters/<class>/<class>_s.png` turnarounds.

512×768 RGBA, transparent, no UI chrome. East / three-quarter, same read as walk E.

| File | Class | Locked look |
|---|---|---|
| `kestrel_select.png` | Kestrel | F+A. Forest-green tattered cloak and gold trim, gold pauldrons, bow and quiver, hood back, face visible |
| `ironjaw_select.png` | Ironjaw | A+A2. Crimson plate, dual double-bit axes, iron-jaw grill with spikes and crest |
| `mender_select.png` | Mender | D2. Cream/gold robe, green lantern staff, open hood, face visible |
| `gloam_select.png` | Gloam | B. Amber eyes, chilling grin, dual curved silver knives, purple cloak and gold trim |
| `bastion_select.png` | Bastion | 2C. Charcoal-grey and gold plate, spiked mace, oversized tower shield |

`ironjaw_select.png` is a smaller file than the others. It is the same canvas and a full figure, with a shorter palette from the ship walk cell.
