# Drawn masters (optional)

These PNGs are TA source sheets, not the path Godot prefers.

Runtime drop is `art/export_2x/characters/` — see that README.

If a lettered export file is missing, the loader may fall back to:

`art/grok_project/anims/<class>_<anim>_<se|ne|sw|nw>.png`

Map: `_se` → pawn `e`, `_sw` → `s`, `_ne` → `n`, `_nw` → `w`. Do not rely on these files being present.
